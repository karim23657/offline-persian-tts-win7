    API

    همهٔ مسیرها با یک اتصال HTTP/1.1 پایدار (keep-alive) سرو می‌شوند؛ مستندات کامل: /api/help 

    GET  /api/health          status, uptime, resident models
GET  /api/models          installed models [{name, loaded}]
GET  /api/catalog         models.json (what you see above)
GET  /api/dict            pronunciation dictionary (user.dict)
POST /api/dict            {"word": "...", "repl": "..."} | {"word": "...", "delete": true}
POST /api/warmup          {"model": "name"} -> load now, report ms
POST /api/unload          {} = free all | {"keep": "m"} = all but m | {"model": "m"}
POST /api/synthesize      {"text": "...", "model": "name", "speed": 1.0, "sid": 0} -> audio/wav
GET  /api/synthesize?text=...   same, via query string (for <audio src>)
GET  /api/help            this list as plain text
