win7-tts

local text to speech connecting...
Persian, English or any other script. The model is loaded once and stays warm.
API
The same engine is available over HTTP, which is useful for scripting and for other programs on this machine.
GET /api/health GET /api/models POST /api/warmup POST /api/synthesize GET /api/synthesize?text=...&model=...
POST /api/synthesize takes JSON and returns audio/wav: {"text":"...","model":"...","speed":1.0,"sid":0,"length_scale":1.0}
